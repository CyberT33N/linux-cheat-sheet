# Microphone Detection Issues

## Bluetooth mic not detected

1. Install PulseAudio Volume Control

   ```shell
   sudo apt-get install pavucontrol
   ```

2. Go to the `Configuration` tab and set the profile `High Fidelity Playback`. Then, under Input devices, you should be able to select your Bluetooth mic input

## Input mic not detected

1. Install PulseAudio Volume Control

   ```shell
   sudo apt-get install pavucontrol
   ```

2. Then, under Input devices, you should be able to select your mic input
