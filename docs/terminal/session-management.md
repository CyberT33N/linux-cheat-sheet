# Terminal Session Management (screen)

- [Ubuntu wiki: Screen](https://wiki.ubuntuusers.de/Screen/)

```shell
sudo apt-get install screen 
```

## Important commands

- The three most important commands respectively key combinations you should know are:
    - Ctrl + A, followed by C to create a new window (see also the difference between session and window)
    - Ctrl + A, followed by SPACE to switch between the individual windows of a session
    - Ctrl + A, followed by D to detach the connection to the current session; the session then continues running in the background
